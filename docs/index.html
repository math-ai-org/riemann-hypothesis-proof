The Magnificent Age of Research

The Riemann
Hypothesis

Posed in 1859. Here it stands as a theorem in a Lean 4 project of 175,187 modules and 17.4 million lines, every one of them reachable from a single statement.

src/Main.lean
theorem riemannHypothesis : RiemannHypothesis := rhOfAll

Every dot is one module: 175,187 in all, placed by its import depth below Main, the glowing point, and colored by library. The chain runs 203 modules deep. Move the pointer to turn it.

  1. 1859Riemann states the hypothesis in his memoir on the number of primes below a given magnitude.
  2. 1900Hilbert includes it in the eighth of his twenty-three problems.
  3. 2000The Clay Mathematics Institute names it a Millennium Prize Problem.
  4. 2026Levent Alpöge publishes this Lean 4 project, whose main theorem is Mathlib's RiemannHypothesis.

Lean project by Levent Alpöge, published at alpo.ge. Repository: math-ai-org/riemann-hypothesis-proof. Every number on this page is computed from the source files.

    The Magnificent Age of Research

    A proof you can rebuild.

    A question from 1859 now sits in a repository anyone can clone. Its main theorem is one line; beneath it lie 818,755 theorems and lemmas that a machine can check one by one, with no referee's judgment in the loop. Run the build, then ask Lean which axioms the result rests on.

    lake exe cache get && lake build
#print axioms riemannHypothesis
