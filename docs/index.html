The Riemann Hypothesis, as a Lean 4 project

A map of a Lean 4 project, built on Mathlib, whose main file proves Mathlib's statement of the Riemann Hypothesis, along with the generalized Riemann Hypothesis for Dirichlet L-functions. Every number on this page is computed from the source files.

Lean project by Levent Alpöge, published at alpo.ge. Repository: math-ai-org/riemann-hypothesis-proof.

The main theorems

src/Main.lean proves five statements. RiemannHypothesis is Mathlib's own definition; the other four are defined in src/Statements.lean, which imports only Mathlib.

TheoremStatement
riemannHypothesisRiemannHypothesis, as defined in Mathlib.
riemannZeta_eq_zero_reEvery zero of the Riemann zeta function, other than the trivial zeros −2(n+1) and the point s = 1, has real part 1/2.
LFunction_ne_zero_of_half_lt_reFor every Dirichlet character χ, L(χ, s) ≠ 0 whenever Re s > 1/2, except at the pole χ = 1, s = 1.
LFunction_eq_zero_reEvery zero of a Dirichlet L-function in the strip 0 < Re s < 1 has real part 1/2.
LFunction_eq_zero_re_of_isPrimitiveThe same statement for primitive Dirichlet characters.
